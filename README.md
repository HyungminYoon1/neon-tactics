# NEON TACTICS — 내일의 공격

적의 다음 공격을 읽고 위치를 바꾸어 도시를 지키는 턴제 전술 퍼즐입니다.

[게임 실행](https://hyungminyoon1.github.io/neon-tactics/) · [WEB LAB](https://hyungminyoon1.github.io/web-lab/) · [소스](https://github.com/HyungminYoon1/neon-tactics)

## 게임

- 12개 임무. 1번은 조작 입문, 7–12번은 전력 10/12 이상을 유지하는 3차 침입 복합 작전입니다.
- BREAKER 밀치기, ANCHOR 끌기, PHASE 위치 교환. 이동과 기술은 각각 1명령이며 3개를 공유합니다.
- 기체마다 턴당 최대 2행동. 물·벽 충돌, 밀리는 기체 열, 광선 아군 오사와 폭탄 연쇄를 계산합니다.
- 현재 공격 순서 및 피해와 명령 확인 후 바뀔 공격선/피해를 구분합니다. 미확정 명령은 취소하거나 확인해야 적 턴을 실행합니다.
- 직선 광선, 십자 포격, 제거 시 폭발하는 적과 예고된 증원. 먼저 제거된 적은 공격하지 않습니다.
- 32회 명령/적 턴 되돌리기, 같은 작전 재시도. 조언을 사용한 성공은 독립 최고 기록에 포함하지 않습니다.

## 조작

1/2/3 기체 선택, Q 이동/E 기술, 방향키 또는 클릭으로 목표 지정, Enter/Space 명령 확인, Z 되돌리기, T 적 턴. 모바일 칸 이동 패드와 확인 버튼도 같은 규칙을 사용합니다.

## 규칙과 기록

모든 명령은 순수 규칙으로 복제 상태를 계산하며 미리보기와 실행에서 동일 함수를 사용합니다. 적 턴은 생존 적의 순서대로 매 공격 당시 경로/첫 피격체를 다시 계산하고 폭발을 적용합니다. 종료 뒤 살아남은 적은 시설 방향으로 다음 의도를 정합니다. 예정 진입 칸이 막히면 가장 가까운 빈 칸(거리→행→열)에 진입합니다. 모든 진입을 마친 적 전멸과 최소 시설 전력이 승리 조건입니다.

성공 점수는 실제 턴/명령/시설·기체 손실/제거 수로 계산합니다. 최고 기록은 페이지 메모리만 사용하고 조언 사용 기록과 분리합니다.

8×8, 기체 3/시설 3/적 최대 7, 처리 엔티티 상한 16. 최대 6턴, 턴당 3명령/기체당 2행동, 취소 32 상태. 연쇄 밀기/폭발 상한 16. 효과 애니메이션만 430ms이며 게임 상태는 실제 명령 시에만 바뀝니다.

상태·최고 기록·설정은 현재 페이지 메모리에만 남으며 탭을 닫으면 사라집니다. 계정, 쿠키, 영구 저장, 전체 사용자 순위, 분석 도구, 서버 API 또는 자동 소리 재생은 없습니다. GitHub 호스팅 로그는 앱의 저장 기능과 별개입니다. 외부 폰트/이미지/패키지 없이 직접 그린 Canvas/SVG/CSS 아트를 사용합니다.

## 실행 및 배포

Node.js 22 이상. 외부 패키지를 설치하지 않습니다.

```sh
npm run dev -- 0
npm test
npm run check
```

개발 서버는 127.0.0.1에서 dist만 제공합니다. main의 Pages 워크플로가 테스트와 공개 파일 검사를 통과한 뒤 dist만 배포합니다. 공개 소스는 GitHub Actions입니다.

## 검증

23 model tests: 모든 임무의 실제 명령·시설·전멸 해답, 미리보기/실행 일치 및 예고/실제 공격 순서, 독립 충돌/수중/교환/행동 예산/폭발·죽은 사수 취소/실패/재현 사례.

1/7/12의 일반 기체·기술 선택, Canvas 목표 지정과 명령 확인으로 실제 성공했습니다. 5900/5160/4280점 일치를 확인했습니다. 키보드 기술, 명령/AP 취소, 실제 적 턴 취소, 전력 리셋과 미확정 목표 상태의 적 턴 차단을 확인했습니다.

모델은 12개 모두 검증했고, 브라우저 완주는 1/7/12를 선택하여 확인했습니다. 390/320px에서는 내부 보드 스크롤, 도움말/선택 메뉴와 조작을 검토합니다. 실제 모바일 하드웨어, 모든 브라우저 및 사람의 난도/재미 평가는 별도 확인이 필요합니다. 원격 CI와 실제 공개 결과는 [최신 통합 공개 검증](https://github.com/HyungminYoon1/web-lab/blob/main/docs/verification.md)을 확인하세요.

AI 에이전트와 제작한 독립 단일 플레이 게임입니다. 기존 서비스 코드는 병합하지 않습니다. UTF-8 without BOM / CRLF.
